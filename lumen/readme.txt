安靜、以文字為主的個人部落格佈景主題，適合中英文寫作。

== Description ==

Lumen 零 JavaScript、不載入網路字型，整個佈景主題只有一個 CSS 檔。

* 一行膠囊頁首；首頁與彙整頁為兩欄瀑布流描邊卡片。
* 全站內容與頁首同寬；只用一種強調色；跟隨系統的自動深色模式。
* 仿宋閱讀字型；中英混排自動留白。
* 文章頁的閱讀時間、標籤、分頁頁碼與附標題的上一篇／下一篇按鈕。
* 分類頁大標題、篇數與麵包屑。
* 「Archives (all posts by year)」頁面範本：依年份列出所有文章。
* 頁首放大鏡下方彈出的小搜尋框（原生 Popover）。
* WordPress 原生巢狀留言，泡泡式版面。
* 內建繁體（zh_TW）與簡體（zh_CN）中文翻譯。

== Installation ==

1. 外觀 → 佈景主題 → 安裝佈景主題 → 上傳佈景主題，選擇 lumen ZIP 並啟用。
2. 外觀 → 選單：指定 Primary menu 與 Footer menu。
3. （選用）新增頁面，範本選「Archives (all posts by year)」，作為文章歸檔頁。
